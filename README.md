# Customer Success Workflow Demo

This is an independent, AI-assisted portfolio demonstration prepared for Ritika.

## What it demonstrates
- New-customer onboarding checklist
- Fictional support-ticket triage and status updates
- Example customer-health signals
- Searchable knowledge-base articles
- A simple support workflow: clarify, guide, follow up, and escalate when needed

## Demo limits
All customer names, tickets, and health scores are fictional. The page has no backend. Changes are stored in the browser's local storage on the device where it is opened. The demo is not affiliated with Canonical or Ubuntu.

## Run locally
Open index.html in a browser.

## Publish with GitHub Pages
Upload index.html and this README.md to a public repository. In repository Settings, open Pages and publish from the main branch and root folder. After GitHub finishes publishing, test the live URL before adding it to LinkedIn.

## Be accurate in interviews
Describe this as an AI-assisted independent demo. Do not present fictional data or simulated workflow actions as results from a real company.
